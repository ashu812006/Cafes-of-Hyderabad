# Hyderabad Cafés

A café discovery and table booking app for Hyderabad. 
Built as a personal project using plain HTML, CSS and JavaScript.

Live demo: https://cafesofhyderabad.netlify.app/

## What it does
- Search and filter cafés by area, price, and category
- Check table availability and book a table
- Get a booking confirmation email
- Save favourites and compare cafés
- Admin dashboard to view all bookings

## Built with
HTML5, CSS3, JavaScript, EmailJS, localStorage
